# Battle Arena - playable builds

Windows builds of Battle Arena, a personal, non-commercial arena combat prototype. It uses art, sounds and data
from Darkfall: Unholy Wars and is not affiliated with or endorsed by its developers.

## Play

1. Download `BattleArena-<version>.zip` from the [latest release](../../releases/latest).
2. Unzip it anywhere and double-click **Play BattleArena.bat**.
   Windows may say it protected your PC: click **More info**, then **Run anyway**.
3. From then on, start the game with **Play BattleArena.bat**: it downloads new versions by itself.

## Playing together

Steam has to be running on both PCs (the launcher starts it). Steam shows you as playing "Spacewar": that is
Valve's free test app the game borrows for online play, so nobody has to forward ports.

- One player clicks **Host a game** on the start screen (allow Battle Arena through the Windows firewall if asked).
- The other picks that game under **Games on Steam**, or right-clicks the host in the Steam friends list and
  chooses **Join Game**, or accepts an invite (host: Esc > **Invite a Steam friend**).
- Both need the same version; the launcher keeps it up to date.

Esc opens the menu. In game: Tab hotbar setup, I inventory, P character, K list of keys.
